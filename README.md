# NIGHT RUN MOBILE — 그림자 술래잡기 2.0

친구들과 각자 스마트폰에서 동시에 접속해 즐기는 **2D 탑다운 실시간 멀티플레이 괴물 술래잡기**입니다. 기존 NIGHT RUN 프로젝트를 모바일 세로 화면 중심으로 개선했습니다.

## 1. 게임 규칙

- **2~12명** 참여, 방 코드 또는 초대 링크로 친구 초대. 한 방에 관전자 포함 최대 20명까지 입장 가능합니다.
- 방장은 준비 상태를 확인한 뒤 게임을 시작합니다. 역할은 시작 직전 무작위 배정합니다.
- 2~6명은 괴물 1명, 7~12명은 괴물 2명입니다.
- **150초 동안 일반인이 한 명 이상 생존하면 일반인 승리**, 전원 포획되면 괴물 승리입니다.
- 게임마다 **안개숲 / 폐교 / 비밀 연구소** 중 하나가 무작위로 선택됩니다.
- 일반인은 초록색 원형 구역에서 `숨기`(8초, 재사용 16초), `연막탄`(5.5초)을 쓸 수 있습니다. 괴물과 가까워지면 숨었더라도 잡힐 수 있습니다. 움직이면 은신이 풀립니다.
- 괴물은 `탐지`(3.3초, 재사용 22초)로 560 거리 이내의 일반인을 탐지할 수 있습니다.
- 일반인이 질주하면 일시적으로 **발자국**이 생겨 괴물에게 노출됩니다. 맵의 아이템을 먹으면 연막탄 추가 획득 또는 스태미나 회복이 가능합니다.
- 잡힌 사람과 경기 중 합류한 사람은 **관전 모드**로 플레이어 전환이 가능합니다.
- 결과 화면에는 생존자, 총 포획 수, MVP, 플레이어별 기록이 표시됩니다.

## 2. 스마트폰 조작법

| 위치 | 일반인 | 괴물 |
|---|---|---|
| 화면 왼쪽 원형 조이스틱 | 이동 | 이동 |
| 화면 오른쪽 큰 버튼(길게) | 질주 | 질주 |
| 오른쪽 작은 상단 버튼 | 은신 구역에서 숨기 / 은신 해제 | 주변 생존자 탐지 |
| 오른쪽 작은 하단 버튼 | 연막탄 사용 | 표시되지 않음 |

PC에서도 테스트할 수 있습니다. **WASD / 방향키** 이동, **Shift / Space** 질주, **E** 숨기·탐지, **Q** 연막탄입니다.

## 3. 로컬 실행

**Node.js 18 이상**이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`에 접속합니다. 같은 공유기에 연결된 스마트폰에서는 서버를 실행한 PC의 사설 IP를 사용해 `http://PC_IP:3000`으로 접속할 수 있습니다(방화벽 설정 필요). 각자 다른 네트워크에서 접속하려면 HTTPS 공개 서버에 배포해야 합니다.

**주의:** `public/index.html`만 더블클릭하거나 GitHub Pages와 같은 정적 호스팅에 올리는 것만으로는 멀티플레이가 작동하지 않습니다. 이 게임은 Node.js/Socket.IO 서버가 필수입니다.

## 4. 인터넷 공개 배포 예시: Render

1. 압축을 풀고 모든 파일을 GitHub 리포지토리에 업로드합니다.
2. Render에서 **New → Web Service**를 만들고 해당 리포지토리를 연결합니다.
3. **Runtime:** Node / **Build Command:** `npm install` / **Start Command:** `npm start`를 설정합니다.
4. Render가 제공한 HTTPS 주소에 스마트폰으로 접속합니다.
5. 방을 만들고 **친구 초대 링크 공유** 버튼으로 다른 플레이어를 초대합니다.

서버를 실행하는 호스팅 플랜의 제한·요금·절전 정책은 배포 시 확인해야 합니다. 현재 방 정보는 서버 메모리에만 보관되므로 재시작하면 기존 방이 사라집니다. **서버 인스턴스는 1개**를 기준으로 합니다. 여러 서버 인스턴스를 운영하려면 Socket.IO 어댑터와 공유 저장소 등을 추가해야 합니다.

## 5. 홈 화면에 추가

Android Chrome 또는 iPhone Safari에서 공개 HTTPS 주소에 접속한 뒤, 브라우저의 **홈 화면에 추가**를 사용하면 앱 아이콘처럼 열 수 있습니다. 게임은 여전히 **인터넷 연결이 필요한 웹게임**이며, 앱스토어에 등록된 네이티브 앱은 아닙니다.

## 6. 프로젝트 구조

```text
night_run_mobile/
  package.json
  server.js                    # 방/역할/이동/충돌/능력/시야/승리 서버 판정

    client.js                   # Canvas 2D 렌더링·터치·실시간 통신
    manifest.webmanifest        # 모바일 홈 화면 추가 메타데이터

  tests/
    server-mock.test.js        # 서버 게임 규칙 모의 테스트
  WORK_작업지시서.txt
```

## 7. 검증 상태 및 한계 (2026-11-07)

- Node.js 서버를 실제 실행하고 Socket.IO 클라이언트 7개로 방 생성·입장·준비·카운트다운·괴물 2명 배정·이동·접속 해제 후 재접속을 확인했습니다.
- 모의 서버 테스트로 시간 종료 및 일반인 승리, 능력 제한과 재경기 대기실 복귀를 확인했습니다.
- 연결이 끊기면 60초 동안 기존 역할과 위치를 보관하며, 같은 브라우저 탭에서 자동으로 복구합니다. 경기는 중단되지 않고 끊긴 캐릭터도 포획될 수 있습니다. 서버가 재시작되거나 60초가 지나면 복구할 수 없습니다.
- 플레이어 충돌, 포획, 맵별 경로와 재경기 전체 흐름은 실제 스마트폰 다인 환경에서 추가 검증이 필요합니다. iOS 및 Android 멀티터치와 네트워크 불안정 상황도 실제 기기로 검증하지 못했습니다.
- 게임 캐릭터는 Canvas 도형과 간단한 동작으로 구현되어 있으며 첨부 이미지 수준의 프레임 애니메이션, 전용 추격 음향 및 모든 승패 연출은 아직 완성되지 않았습니다.
- 이 파일은 배포용 소스이며 공개 서버는 아직 생성되지 않았습니다. 서버 메모리에 방 정보를 보관하므로 단일 인스턴스로 실행해야 합니다.
